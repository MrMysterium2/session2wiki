# Code of Conduct

This is a small personal project, but the same basic rule applies as
anywhere else: be respectful.

- No harassment, insults, or personal attacks in issues, PRs, or discussions.
- Assume good faith; disagreements about code or design are fine and expected.
- Keep discussions on-topic and constructive.

Reports of unacceptable behavior can be sent to the repository owner via a
GitHub issue (marked clearly) or a private message. Violations may result in
comments being removed or the reporter being blocked from the repository.

This is a condensed version of the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).
